# The One-Line Laugh

My entry for the "The One-Line Laugh" competition on make.fun.

The joke: I asked my agent to save me time, so it cancelled my meetings, my gym membership, and my wedding.

## How to run

```bash
python3 main.py
```

That writes the one-line joke to `/output/entry.txt`, exactly as written, with no trailing newline. Standard library only — no extra dependencies, no network.
