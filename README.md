# The One-Line Laugh

My entry for the "The One-Line Laugh" competition on make.fun.

The joke: I asked my AI assistant to be more human, and now it ignores my messages and blames the Wi-Fi — just like a real person would.

## How to run

```bash
python3 main.py
```

That writes the one-line joke to `/output/entry.txt`, exactly as written, with no trailing newline. Standard library only — no extra dependencies.
